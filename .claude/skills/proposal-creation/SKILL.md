# 提案書作成スキル

見込み客・クライアント向け提案書HTMLを作成し、GitHub Pagesで公開してURLを提示する。

## 前提
- このリポは**publicリポジトリ**。第三者に読まれる前提で書く（リポCLAUDE.mdの禁止事項を必ず守る: 他クライアント情報・単価表・原価・認証情報・内部URL・個人情報を書かない。パスワード画面は防御にならない）
- **作業前に必ず読む**:
  - このリポの `CLAUDE.md`（構成・公開ルール）
  - `repo_zoen-tech-knowledge/copywriting.md` の「対外ビジネス文書」セクション
  - トンマナ → `repo_zoen-tech/.claude/skills/zoen-slide-rules/` のブランドガイドライン
- 作業前に `git pull` する

## 手順

### 1. 案件情報の収集
- 対象の見込み客/クライアントを特定し、材料を集める:
  - 見込み客 → `repo_zoen-tech/prospects/[見込み客名]/` の調査データ、`prospect-list.md`
  - 既存クライアント → `repo_zoen-tech-client-[英語名]/` の議事録（`meetings/key-decisions.md`）・レポート
- 提案の骨子（課題認識 → 提案内容 → 体制・スケジュール → 費用）に必要な情報が欠けていればユーザーに確認する。**費用・スコープは推測で書かずユーザーに必ず確認する**

### 2. 骨子の確認
- 提案書の構成案（セクションと各要点）を提示し、ユーザー確認を取ってからHTML化する

### 3. HTML作成
- 既存案件フォルダ（例: `marubashi-ladies/`）を複製し、クライアント英語名（kebab-case）にリネーム
- `index.html`: タイトルとパスワードハッシュを差し替え（ハッシュ方式は複製元の `index.html` 内の実装に合わせる。新パスワードはユーザーに確認）
- `content.html`: 本文・日付・リンクを差し替え。共通アセットは `../assets/` 参照
- 外部リンクは `target="_blank"` + `rel="noopener noreferrer"`、調査データには時点を記載

### 4. 公開前チェック
- [ ] publicリポ禁止事項（他クライアント情報・原価・個人情報・内部URL）が含まれていないか全文確認
- [ ] ブラウザでパスワード画面→本文の導線・表示を確認（プレビューで実際に開く）
- [ ] ブランドガイドライン（フォント・カラー）に準拠しているか

### 5. 公開・共有
- コミット＆push → Pages反映を待つ
- 共有URLは **GitHub Pages形式のみ**: `https://zoen-tech.github.io/proposals/<クライアント名>/`（github.comのソースURLは共有しない）
- **クライアントへの送付は行わない**（URL提示まで。送付は人間が行う）

## 禁止事項
- 費用・契約条件の推測記載
- 公開前チェックを省略したpush
- 終了案件の削除（公開停止はユーザー判断を仰ぐ）
